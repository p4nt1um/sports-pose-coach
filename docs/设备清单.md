# 体育组设备清单（一页纸）

> 用途：采购确认 + 开课前自检。技术细节见 [../README.md](../README.md) 的「运行环境要求」。

## 一、要确认的四件事

| # | 项目 | 要求 | 怎么确认 | 必需 |
|---|---|---|---|---|
| 1 | 浏览器 | Chrome 或 Edge，**91 版本以上**（2021 年之后装的都满足） | 地址栏输入 `chrome://version` 看版本号 | ✅ |
| 2 | 显卡 | **集成显卡就行**（Intel HD 620 / UHD 630 及以上） | 见第二节第 5 步：右上角徽标显示 `GPU` | ✅ |
| 3 | 摄像头 | 720p 及以上；**建议外接 USB 摄像头** | 笔记本内置的 720p 可用，但拍不到侧面动作 | ✅ |
| 4 | 运行环境 | 装了 Node.js 18+ **或** Python 3（有其一即可） | 双击 `启动.bat`，窗口里会打印它用的是哪个 | ✅ |

**不需要**：独立显卡、联网、装客户端、装数据库、`npm install`。

磁盘占用约 27 MB。整机内存建议 8 GB（最低 4 GB）。

## 二、开课前 5 分钟检查

1. 双击项目根目录的 **`启动.bat`** —— 会弹出一个黑色窗口，稍后自动打开浏览器
2. 首屏点 **「动作计数（上课用）」**
3. 下拉选今天要练的动作
4. 按下面的「机位」把摄像头摆好，然后点 **「开始」**
5. 看一眼**右上角的徽标**：
   - `GPU · 运行中` → 一切正常
   - `CPU · 运行中` → 这台机器没走显卡，先更新显卡驱动；仍不行的建议换机
6. **点开始后有几秒钟不出数字是正常的**（首次要编译图形程序，最长约 5 秒），等它出来即可

> 上课过程中**不要关掉那个黑色窗口** —— 它就是本机服务，关了页面就断了。

## 三、机位（照做就行）

| 动作 | 类型 | 机位要求 |
|---|---|---|
| 深蹲 | 计数 | 正面或侧面，全身入镜 |
| 开合跳 | 计数 | **正面**（侧对会让肩宽失真） |
| 俯卧撑 | 计数 | **侧面**，镜头压低到与身体同高 |
| 仰卧起坐 | 计数 | **侧面**，镜头压低到地面附近 |
| 原地高抬腿 | 计数 | **正面**，两条腿都要看得见 |
| 马步 | 计时 | 正面或侧面，全身入镜 |
| 靠墙静蹲 | 计时 | **侧面**，最好把墙面也拍进画面 |

**通用三条**：① 人和镜头之间不要站别人；② 光线别逆光（背对窗户会只剩黑影）；
③ 镜头高度尽量与动作部位齐平 —— 三条里最容易被忽略的是第 ③ 条。

> 靠墙静蹲有一条**程序验不了**的：它只能确认「膝角达标 + 躯干贴直」，
> **确认不了背是不是真的贴着墙**。所以机位要求把墙拍进来，由老师用眼睛判断。

## 四、出问题怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 `启动.bat` 窗口一闪而过 | 没装 Node.js / Python，或 `tools` 目录不在 | 窗口会停下来打印原因；按提示装 Node.js 18+ 再试 |
| 浏览器打开是白屏 | `vendor` 目录缺失（拷贝时漏了）或浏览器太老 | 确认 `vendor` 目录存在；确认浏览器版本 ≥ 91 |
| 页面能开但点开始没反应 | 摄像头被别的程序占用 | 关掉微信/钉钉/腾讯会议等，刷新页面重试 |
| 一直显示 `CPU` 而不是 `GPU` | 显卡驱动太旧 | 更新显卡驱动，重启浏览器 |
| 数字明显偏少 | 机位不对（尤其是侧面动作拍成了正面） | 对照第三节的机位表重摆 |
| 数字偶尔多 1 次 | 起身时腿有晃动 | 正常现象，可容忍；系统会把抖动排除掉 |
| 某个学生总是数不准 | 遮挡 / 逆光 / 出画 | 让他挪一步，或换更靠中间的位置 |
| 换台电脑后参数变了 | 调参存在本机浏览器里，不跟着人走 | 在调试台用「备份存档」导出，在新机器「载入存档」 |

## 五、不要做的事

- ❌ **不要直接双击 `v1-counter.html`** —— 必须走 `启动.bat`（浏览器的安全限制，不是 bug）
- ❌ 不要用手机浏览器打开 —— v1 不做手机适配（局域网 IP 不是安全上下文）
- ❌ 不要上课中途关掉黑色窗口
- ❌ 不要改 `data/exercises.json` 里的数字 —— 要调标准请用「参数调试台」，改完会自动保存

---

**要调动作标准**（比如"这个班蹲得浅一点也算"）：打开「参数调试台」`tools/tune.html`，
拖滑块时画面上的曲线和计数会**立刻按已录的信号重算**，不用重做动作。调好自动保存，下次打开还在。
